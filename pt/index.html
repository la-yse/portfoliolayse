SOBRE MIM

Sou uma Desenvolvedora Front-End com base em Lisboa, Portugal. O meu objetivo é criar websites que coloquem a experiência do utilizador em primeiro lugar.

Como desenvolvedora, priorizo o uso de tecnologias de acordo com as exigências de cada projeto, em vez de seguir uma receita única. Cada website é desenvolvido com as ferramentas adequadas às suas necessidades, mantendo as soluções eficientes, focadas e fáceis de manter.

À medida que a tecnologia se torna cada vez impessoal, acredito que a individualidade continua a ser um diferencial.Websites feitos por pessoas, para pessoas.
